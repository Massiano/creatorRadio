Add song metadata

Paste one clip object, a wrapped {clip, log, source} blob (like a page-scrape dump), or a JSON array of clips for a batch. Nothing is de-duplicated or merged across shapes — a "full" fetch and a "playlist" fetch for the same song are kept as two separate raw blobs.

Resolve Suno URLs

Accepts a bare id, a suno.com song/playlist link, a cdn1 mp3/mp4 link, a cdn2 image link, or a suno.com/s/… share link (resolved by following its redirect, since a share code isn't the song id).

Retrieve playlist

Live fetch calls studio-api.suno.ai first, then falls back to scraping and RSC-parsing the public playlist page — same pattern as a single-clip fetch. This will only succeed if your browser context isn't blocked by CORS for suno.com (e.g. running inside a userscript on the site itself). If it fails, paste the page's HTML / RSC text below instead.

URL templates

{id} is substituted. Confirmed from Suno's current site: song page and cdn1 mp3. Share/playlist/video/image templates are best-guess — adjust here if Suno's format differs from what you see in practice.
